# Lactic trademark policy

The Lactic code is MIT licensed: you can use, change and ship it however you like. The MIT license covers the code only. It does not cover the Lactic name, the Lactic logo or the lactic.fit domain, which belong to James Blair.

This page says how you can use the name and logo. The goal is simple: riders should always know whether they are using Lactic itself or something built from it.

## Fine without asking

- Saying your project is "based on Lactic", "a fork of Lactic" or "works with Lactic".
- Writing about Lactic, reviewing it or teaching people to use it.
- Using the name and logo to link to Lactic, its releases or lactic.fit.
- Running an unmodified build of Lactic, or building it from this repository for yourself.

## Please don't

- Ship a modified version or a fork under the name Lactic, or with the Lactic logo or app icon. Give it its own name and icon.
- Use a name or logo close enough to be confused with Lactic for a training app or service.
- Suggest that your project, product or service is official, endorsed by or affiliated with Lactic when it isn't.
- Use the name in a domain, app store listing or account handle in a way that could pass as the official project.

## Forks

If you fork Lactic and publish your version, rename it and replace the logo and icon before release. Keeping the copyright notice from the MIT license is still required, and a line such as "Based on Lactic" is welcome.

## Questions

Not sure whether something is fine? Open an issue at https://github.com/blairj09/lactic/issues and ask.
