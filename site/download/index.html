All downloads

Mac

Apple silicon (M1 or later).

Download .dmg
  1. Open the .dmg and drag Lactic to Applications.
  2. Lactic isn't signed by Apple yet, so run this once in Terminal: xattr -cr /Applications/Lactic.app
  3. Open Lactic.

Windows

Windows 10 or 11, 64-bit.

Download installer
  1. Run the installer.
  2. Windows warns about an unknown publisher. Choose More info, then Run anyway.
  3. Open Lactic from the Start menu.

Linux

64-bit. AppImage for any distro, or a .deb for Debian and Ubuntu.

AppImage .deb
  1. AppImage: chmod +x Lactic_*.AppImage, then run it.
  2. .deb: sudo apt install ./Lactic_*_amd64.deb
