# Security

Found a security problem, like a way for a plugin to escape its sandbox or a key leaving the keychain? Please don't open a public issue. [Report it privately](https://github.com/blairj09/lactic/security/advisories/new) on GitHub, or email **help@lactic.fit**, with the details and steps to reproduce. We'll reply as soon as we can.

Lactic is in beta, so fixes ship in the latest release only.
